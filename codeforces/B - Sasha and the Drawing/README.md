# [B. Sasha and the Drawing](https://codeforces.com/contest/1929/problem/B)

---
Even in kindergarten, Sasha liked a girl. Therefore, he wanted to give her a drawing and attract her attention.As a drawing, he decided to draw a square grid of size n×nn×n, in which some cells are colored. But coloring the cells is difficult, so he wants to color as few cells as possible. But at the same time, he wants at least kk diagonals to have at least one colored cell. Note that the square grid of size n×nn×n has a total of 4n−24n−2 diagonals.Help little Sasha to make the girl fall in love with him and tell him the minimum number of cells he needs to color.

### Input
InputEach test consists of multiple test cases. The first line contains a single integer tt (1≤t≤10001≤t≤1000) — the number of test cases. The description of the test cases follows.The only line of each test case contains two integers nn and kk (2≤n≤1082≤n≤108, 1≤k≤4n−21≤k≤4n−2) — the size of the square grid and the minimum number of diagonals in which there should be at least one colored cell.

### Output
OutputFor each test case, output a single integer — the minimum number of cells that need to be colored.
