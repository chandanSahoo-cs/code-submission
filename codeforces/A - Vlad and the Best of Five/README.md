# [A. Vlad and the Best of Five](https://codeforces.com/contest/1926/problem/A)

---
Vladislav has a string of length 5, whose characters are each either A or B.Which letter appears most frequently: A or B?

### Input
InputThe first line of the input contains an integer t (1≤t≤32) — the number of test cases.The only line of each test case contains a string of length 5 consisting of letters A and B.All t strings in a test are different (distinct).

### Output
OutputFor each test case, output one letter (A or B) denoting the character that appears most frequently in the string.
