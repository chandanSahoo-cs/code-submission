# [A. Polycarp and the Day of Pi](https://codeforces.com/contest/1790/problem/A)

---
On March 14, the day of the number ππ is celebrated all over the world. This is a very important mathematical constant equal to the ratio of the circumference of a circle to its diameter.Polycarp was told at school that the number ππ is irrational, therefore it has an infinite number of digits in decimal notation. He wanted to prepare for the Day of the number ππ by memorizing this number as accurately as possible.Polycarp wrote out all the digits that he managed to remember. For example, if Polycarp remembered ππ as 3.14153.1415, he wrote out 31415.Polycarp was in a hurry and could have made a mistake, so you decided to check how many first digits of the number ππ Polycarp actually remembers correctly.

### Input
InputThe first line of the input data contains the single integer tt (1≤t≤1031≤t≤103) — the number of test cases in the test. Each test case is described by a single string of digits nn, which was written out by Polycarp.The string nn contains up to 3030 digits.

### Output
OutputOutput tt integers, each of which is the answer to the corresponding test case, that is how many first digits of the number ππ Polycarp remembers correctly.
