# [A. Battleworld: Doom's Countdown](https://codeforces.com/gym/588606/problem/A)

---
Doctor Doom has created Battleworld during the events of Secret Wars. In one of the rooms, Molecule Man is imprisoned, and the room is encrypted with a secret code.Dr. Reed Richards (Mr. Fantastic), a brilliant scientist, must enter the correct code to free Molecule Man and save the multiverse. However, Dr. Richards has forgotten the correct code among n possible distinct codes he has prepared.Dr. Richards will attempt the codes in the following order:   Codes are entered in non-decreasing order of their lengths.  Among codes of the same length, they are tried in arbitrary order. Each attempt to enter a code takes 1 second. Additionally, the chamber has a security system that complicates the process:   If k incorrect codes are entered consecutively, the security system triggers a 7-second delay before Dr. Richards can make another attempt.  As soon as the correct code is entered, Molecule Man is freed, and the process stops immediately.

### Input
InputThe first line of input contains two integers n and k (1≤n,k≤100):   n: the number of possible codes that Dr. Reed Richards can try.  k: the number of failed attempts after which the security system triggers a 7-second delay. The next n lines contain n distinct codes:Each code is a non-empty string of Latin letters and digits, and the length of each code does not exceed 100 characters.The last line of input contains the correct code to unlock the chamber where Molecule Man is trapped. It is guaranteed that this correct code is one of the n provided codes.

### Output
OutputPrint two integers:   The minimum time (in seconds) Dr. Richards needs to free Molecule Man in the best-case scenario.  The maximum time (in seconds) Dr. Richards might need to free Molecule Man in the worst-case scenario.
NoteFirst Test Case:Doctor Reed Richards has 5 distinct codes to try: cba, abc, bb1, abC, and ABC. The correct code is abc.Best Case: If the correct code abc is entered on the first attempt, Dr. Richards spends exactly 1 second. Thus, the minimum time is 1 second.Worst Case: In the worst case, Dr. Richards enters all incorrect codes before the correct one.The process proceeds as follows:First 2 attempts are incorrect: 2 seconds. After 2 consecutive failures, a 7-second delay is triggered.Next 2 incorrect attempts: 2 seconds. Another 7-second delay.Finally, the correct code is entered: 1 second. Total: 2+7+2+7+1=19 seconds. Thus, the output is: 1 19
