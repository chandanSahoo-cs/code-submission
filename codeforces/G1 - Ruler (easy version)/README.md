# [G1. Ruler (easy version)](https://codeforces.com/contest/1999/problem/G1)

---
This is the easy version of the problem. The only difference between the two versions is that in this version, you can make at most 1010 queries.This is an interactive problem. If you are unsure how interactive problems work, then it is recommended to read the guide for participants.We have a secret ruler that is missing one number xx (2≤x≤9992≤x≤999). When you measure an object of length yy, the ruler reports the following values:   If y<xy<x, the ruler (correctly) measures the object as having length yy.  If y≥xy≥x, the ruler incorrectly measures the object as having length y+1y+1.  The ruler above is missing the number 44, so it correctly measures the first segment as length 33 but incorrectly measures the second segment as length 66 even though it is actually 55. You need to find the value of xx. To do that, you can make queries of the following form:  ? a b? a b — in response, we will measure the side lengths of an a×ba×b rectangle with our ruler and multiply the results, reporting the measured area of the rectangle back to you. For example, if x=4x=4 and you query a 3×53×5 rectangle, we will measure its side lengths as 3×63×6 and report 1818 back to you. Find the value of xx. You can ask at most 1010 queries.

### Input
InputEach test contains multiple test cases. The first line of input contains a single integer tt (1≤t≤10001≤t≤1000) — the number of test cases.
InteractionThere is no initial input for each test case. You should begin the interaction by asking a query.To make a query, output a single line of the form ? a b? a b (1≤a,b≤10001≤a,b≤1000). In response, you will be told the measured area of the rectangle, according to our secret ruler.When you are ready to print the answer, output a single line of the form ! x! x (2≤x≤9992≤x≤999). After that, proceed to process the next test case or terminate the program if it was the last test case. Printing the answer does not count as a query.The interactor is not adaptive, meaning that the answer is known before the participant asks the queries and doesn't depend on the queries asked by the participant.If your program makes more than 1010 queries for one set of input data, makes an invalid query, or prints the wrong value of xx, then the response to the query will be −1−1. After receiving such a response, your program should immediately terminate to receive the verdict Wrong Answer. Otherwise, you can get an arbitrary verdict because your solution will continue to read from a closed stream.After printing a query do not forget to output the end of line and flush the output. Otherwise, you may get Idleness limit exceeded verdict. To do this, use:   fflush(stdout) or cout.flush() in C++;  System.out.flush() in Java;  flush(output) in Pascal;  stdout.flush() in Python;  see the documentation for other languages. HacksTo make a hack, use the following format.The first line should contain a single integer tt (1≤t≤10001≤t≤1000) — the number of test cases.The only line of each test case should contain a single integer xx (2≤x≤9992≤x≤999) — the missing number on the ruler.
