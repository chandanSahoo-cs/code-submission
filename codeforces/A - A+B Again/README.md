# [A. A+B Again?](https://codeforces.com/contest/1999/problem/A)

---
Given a two-digit positive integer nn, find the sum of its digits.

### Input
InputThe first line contains an integer tt (1≤t≤901≤t≤90) — the number of test cases.The only line of each test case contains a single two-digit positive integer nn (10≤n≤9910≤n≤99).

### Output
OutputFor each test case, output a single integer — the sum of the digits of nn.
